# Orkla-Report
Orkla: Dragon Con Detective is a beginner-level OSINT investigation scenario created by KASE Scenarios. The objective is to test your ability to investigate real-world locations, analyze images and audio, and use publicly available information to solve investigative challenges.

The scenario follows a fictional investigator named Orkla, who gives you several assignments to determine whether you have the OSINT skills needed to assist with future investigations.

## Objective
The main objectives of the room are:
- Visually extract important information from images and videos.
- Apply basic OSINT tools and online resources to answer investigative questions.
- Practice critical thinking and analytical reasoning.
- Learn how to connect different pieces of publicly available information to identify people and locations.

## Skills Gained
| Skill                            | What you learn                          |
|----------------------------------|-----------------------------------------|
| Open-Source Intelligence (OSINT) |	Gather and analyze publicly available information. |
| Geolocation                      |	Identify locations using visual clues and maps. |
| Reverse image searching          | Find information about images and objects using Google Lens. |
| Audio analysis                   | Extract clues from audio recordings and transcripts. |
| what3words                       |	Identify precise locations using three-word combinations. |
| Public-record research           |	Search historical records and databases. |
| Information verification         |	Compare multiple sources to confirm findings. |
| Critical thinking                |	Connect seemingly unrelated clues to solve investigations. |
